# ExecPlan skill evaluation maintenance

For definition or grader changes, use [authoring scenarios and public CLI checks](authoring-scenarios.md). Keep deterministic cases, qualitative document review, and sampled performance evidence separate. These are maintainer instructions, not plan-execution steps.

Use [planning boundaries](planning-boundaries.md) to exercise triage, discovery and owner decisions, plan destinations, unavailable proof, and preservation of reusable lessons before archival.

Use the [size checkpoint fixtures](size-checkpoints.md) to test the byte boundary, resumed conversion, large task indexes, repeat checkpoints and completion-only exception against files on disk.

Record the tested `SKILL.md` SHA-256 with each reported score. When wording changes after a selection, retain the old selection and identify the working snapshot separately. Keep original grades alongside any regrade or manual assessment of the same artifacts.
