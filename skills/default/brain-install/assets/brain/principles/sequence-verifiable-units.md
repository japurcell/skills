# Sequence Verifiable Units

Start from a known baseline. Group the edits needed for one observable result and run its check before the next dependent unit, including when a tool makes the edits. During a [planned migration](outcome-oriented-execution.md), use the declared phase check for each unit and verify the whole system at completion.
