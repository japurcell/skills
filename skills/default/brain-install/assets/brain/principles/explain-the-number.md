# Explain the Number

Before measuring or acting on a performance or evaluation result, decide what result would change the decision and what variation counts as noise. Measure the actual limiter during a run. List plausible alternative explanations for the number, such as skipped work, caching, errors, or noise, and rule them out with evidence.

Keep the run count, spread, and measured limiter alongside the reported result.
