## Completion semantics

When changing completion semantics, review the producer's [historical reconciliation scenarios](../../spec-to-tasks/evals/update-scenarios.md) and this skill's [sandbox scenarios](evals.json). Include incomplete or stale all-true input, unresolved verification, commit audits, and a repeat completed invocation using genuine progress evidence. Fresh-manifest grading alone does not establish historical proof coverage. Keep current authority, context sufficiency, actual dependencies, negative cases and integrated acceptance under semantic review.
