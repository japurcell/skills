## Use For

Transitions, animations, and subtle polish across UI frameworks.

## Prefer

- Motion that clarifies hierarchy, continuity, or state change.
- Built-in framework transitions first.
- Short, purposeful animations.
- Respect for reduced-motion expectations where available.

## Avoid

- Decorative animation that delays interaction.
- Multiple animations for the same state change.
- Animation that hides focus, selection, validation, or loading state.

## Review

- Does motion improve clarity?
- Is the app responsive while animation runs?
- Can it be simplified to built-in behavior?
