# Recall

Use `python3 skills/agent-brain/scripts/agent-brain.py recall` before relying on repository guidance. Without a known task scope, recall returns required startup guidance and universal established policy, not every conditional fact. When the task is known, add one or more `--path`, `--concept`, `--action`, `--dependency`, `--provider`, or `--runtime` selectors, or `--query TEXT`. Repeat a selector to add values. Use `--all-guidance` only for explicit library browsing.

Structured selectors use OR within one list and AND across known dimensions. A path `*` matches within one segment, `?` matches one non-separator character, and `**` matches zero or more path segments. Unknown selector values broaden retrieval and set `complete` false with a scope gap. Established universal policies remain in text searches even when their wording does not match the query. Required references expand transitively; a whole-artifact read also closes references from its contained units and is delivered once.

The output is informational context for the foreground agent. Read and apply relevant constraints before acting, but do not describe the CLI result as a delivery receipt or claim that the host applied it. JSON includes unit identities, effective applicability, source and input revisions, required references, gaps, and delivered artifacts. Unit delivery omits metadata comments; whole-artifact delivery preserves exact UTF-8 source text and indicates that detailed evidence comments may be included. Default evidence output lists availability and source references; `--show-evidence` requests detailed notes. `--investigate` includes candidates, which never satisfy established mandatory reads. Check `complete`, `gaps`, and `scope_status` before relying on retrieved context. `--json` may appear before or after `recall`; execution errors with `--json` produce a structured result on stdout and an actionable diagnostic on stderr.

The optional `--config PATH` selects a strict JSON configuration. Version 1 supports whole-document and heading-section mappings with typed metadata, plus the legacy whole-document shorthand. Startup/reference reads can request `unit` or `whole`. Mappings are read-only, and paths must resolve within declared knowledge roots. See [the configuration example](../examples/config-v1.json), [configuration schema](../schemas/config-v1.schema.json), [metadata schema](../schemas/metadata-v1.schema.json), and [metadata example](../examples/metadata-authoring-v1.md).

If configuration is absent or invalid, `status` and `doctor` explain the observed state without creating files. A missing mapping does not mean the repository has no other obligations; inspect relevant repository instructions directly when necessary.
