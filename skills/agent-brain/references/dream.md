# Dream

The intended command accepts UTF-8 JSON input using `--input PATH` or `--input -`, along with an integration-issued `--invocation-file`. A path or provider-named environment variable does not establish identity or authority.

Dream execution and cycle tracking belong to a later milestone. Current integrations issue learn registrations only, so dream rejects absent or mismatched authority before reading semantic input or creating state. Report this operation as unavailable and do not claim that review, pruning, or cycle completion occurred. The foreground agent will perform semantic work when an enabled, supported integration supplies eligible context. The CLI launches no model.
