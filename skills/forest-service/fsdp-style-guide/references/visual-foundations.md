# Visual Foundations

Use for brand, color, typography, spacing, icons, imagery, and hierarchy.

## Branding

- Use Forest Service identity consistently.
- Public-facing branding changes need Communications approval.
- Prefer FSDP and USWDS visual patterns over custom styling.

## Color

Prefer Forest Service palette and USWDS equivalents.

| Purpose    |      FSDP | USWDS equivalent |
| ---------- | --------: | ---------------: |
| USFS green | `#005838` |        `#204e34` |
| USFS brown | `#6a5147` |        `#524236` |
| USFS gold  | `#ffd51d` |        `#face00` |
| USFS cream | `#f4e1be` |        `#f1e5cd` |
| Text base  | `#333333` |        `#3d4551` |

Additional USDA accents: `#002d72`, `#005440`, `#0068b1`.

Rules:

- Use USFS green for primary call-to-action styling where appropriate.
- Use warm accents, base colors, and alert colors for hierarchy, status, or emphasis.
- Do not use color as decoration when it hurts readability.
- Do not rely on color alone to convey meaning.
- Maintain accessible contrast.

## Typography

- Use Roboto-family sans serif for digital UI.
- Use Merriweather only when an approved serif voice is needed.
- Keep headings, labels, and body text legible.
- Prefer dark gray body text such as `#333333` over pure black where FSDP applies.

## Layout

- Use clear hierarchy and generous whitespace.
- Make heading, body, metadata, status, and actions easy to distinguish.
- Rounded corners are preferred on square UI components.
- For web layouts, use FSDP/USWDS grid consistently; do not mix layout systems without reason.

## Icons and imagery

- Use each icon consistently with one meaning.
- Pair non-obvious icons with visible text.
- Keep decorative icons decorative.
- For web, use Font Awesome or USWDS SVG icons.
- Prefer USDA/USFS-owned imagery.
- Use hero imagery to support mission, culture, or page purpose.
- Keep text over images readable with overlays or callout containers.
- Avoid busy imagery that competes with content.
- Optimize large hero images for responsive display, about `2048x1024`, while keeping file size reasonable.
