# Public Web/App Surface

Use for public-facing websites and web apps.

## Must follow

- Full FSDP branding and accessibility rules apply.
- Public header is locked down: USDA mark first, then USFS shield, then Forest Service name.
- Do not invent alternate public branding without approval.
- Footer should follow standard USDA/USFS expectations, including required public-policy links where applicable.
- Meet Section 508 and WCAG 2.2 AA.

## Official government banner

- Use only on real official `.gov` or `.mil` HTTPS sites.
- Use standard banner text; do not customize it.
- Show it on every page of an official site.
- Do not use it on test, prototype, or unofficial sites if it could mislead users.

## HTML accessibility

- Use one `h1`.
- Keep heading order logical.
- Ensure keyboard access and visible focus.
- Tie labels to controls.
- Keep search, tooltips, banners, and file inputs usable if JavaScript fails.
