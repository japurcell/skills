# Non-Web Surface

Use for slide decks, documents, posters, desktop-app mockups, and other non-web artifacts.

## Apply intent, not literal web structure

- Keep One USDA and Forest Service identity through approved color, type, icon, imagery, and content choices.
- Preserve clear hierarchy, readable spacing, concise labels, and explicit feedback language.
- Translate accessibility into the medium:
  - logical reading order
  - strong contrast
  - descriptive labels
  - readable type size
  - meaning not dependent on color alone
- Do not force web-only mechanics such as government banners, web footers, or paginated web tables onto artifacts that do not need them.
- If the artifact will become a web screen, keep layout and components close to FSDP/USWDS patterns to reduce implementation drift.

## Examples

- Slide deck: use approved branding and attribution in the slide master instead of copying a web footer.
- Desktop-app mockup: keep confirmation and destructive-action patterns, but omit web banner/footer rules unless relevant.
