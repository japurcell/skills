Set `OBSERVABILITY_LOG_PATH` to a writable disposable path for the Copilot/Gemini shell guard suites; their read-only observability writes must not reach the real installed log.
- Copy adapters together with every provider-local helper into isolated fixtures. Missing or corrupt policy helpers must deny in block and warn modes. Test the interpreter versions affected by parser or import changes; macOS execution and a non-Windows PowerShell skip do not establish native Windows behavior.
- Compare frozen, complete hook subprocesses with identical provider, case, interpreter, inputs, and successful logging conditions. Preserve per-case decisions, source fingerprints, raw samples, first-process observations, median/p95/MAD, repeated-pair variation, and concurrency separately. Source and read-only observability diagnostics do not prove installed behavior. A benchmark exit `0` checks its decisions, not latency acceptance. External adapters checking completed log writes after the maintained runner returns must retain temporary log homes through that verification and clean them in `finally`; otherwise deleted fixture logs cause false failures. Keep these checks outside measured hook elapsed time.
- For the retained [Tool Guardian tuning contract](../../../docs/tool-guardian-tuning/ExecPlan.md#validation-and-acceptance), use two alternating matched warm pairs with 25 measured samples and three warmups, and at least 25 independent fresh-copy cold launches per case/condition with zero provider bytecode. Warm allowances are +2 ms median/+5 ms p95; cold allowances are +5/+10 ms. OS and standard-library caches remain uncleared. An isolated violation requires an exact targeted repeat; retain the original failed observation and reject an unexplained or repeatable violation. Earlier zero-regression failures and rejected optimization reports remain historical failures.
- Use `scripts/benchmark-tool-guard-resources.py` with the contract's 500 ms finite-case ceiling for input-bound changes. Native macOS `/usr/bin/time -l` reports RSS in bytes through a separate launch, so wrapper cost is excluded from latency. A sandbox denial of `sysctl kern.clockrate` makes RSS collection unavailable; use an approved native collector and retain the failure. These measurements do not prove a universal raw-JSON memory bound. Optional optimization ablations must retain per-case benefit, regression, and inconclusive outcomes rather than claiming blanket gains.
- Treat a timed-out review as partial findings, not security approval. Do not rerun checks solely because of a conflict-free rebase; rerun affected checks when conflicts, changed source, or an unresolved concern justify them.
