# Shell Scripts - Known Issues

- Keep shell and PowerShell guidance separate so agents load only the rules relevant to the current task.
- `bash`-specific logic should not silently rely on POSIX shell behavior. `[[ ... ]]` is bash-only; use portable `[ ... ]` or explicit bash conditions when the script is intentionally bash-specific.
- `grep -R` follows symlinks by default, so shell checks that search repo trees can produce false positives through preserved symlinks. Prefer `find <tree> -type f -exec grep -l <needle> {} +` when proving "no regular file under the tree contains X".
- Temporary files must be created under a controlled path and cleaned up with `trap`/`rm -f` so failed shell scripts do not leave stale state behind; do not rely on ad hoc `mktemp` usage without cleanup logic.
- Checking only `yaml.__version__` does not prove the OKF linter loaded its pinned parser: a matching site package can mask an absent vendor tree. Also verify that `yaml.__file__` resolves below `scripts/vendor/yaml/`.
- On case-insensitive filesystems, an OKF fixture named `index.md` can overwrite an existing `INDEX.md` in the same directory. Remove the canonical copy before creating the reserved-name case, then assert the intended diagnostic.
- On case-insensitive filesystems, `one.md` and `ONE.md` cannot coexist as Codex-agent converter fixtures. The converter suite checks the same case-folded output collision through `validate_agent_collisions` on every host and retains the two-file CLI assertion where the filesystem supports both names.
- OKF Markdown masking must scan comments, fences, and inline code left-to-right so the first active construct owns contained delimiters. Replace ignored characters with spaces while preserving newlines so later diagnostic columns do not shift. Valid unclosed fences and comments extend through EOF; backtick fence info strings containing backticks are not valid openers; inline code closes only on an exact-length backtick run.
- Regex-only Markdown link extraction misses balanced labels, balanced or escaped parentheses, and angle-bracket destinations. Preserve the deterministic scanner and its public-CLI regression cases when changing link validation.
- Unquoted variable expansion is a common shell failure mode in loops and path checks. Prefer `"$var"` for untrusted values and avoid building commands from unescaped string fragments.
- Python can replace a chosen broken-pipe exit code with `120` while flushing buffered output at shutdown. `scripts/test-all.py` flushes inside its exception boundary and redirects failed output descriptors to the null device before returning `141`.
- On native Windows, Python `stat.S_IMODE()` reflects emulated read/write bits rather than a Unix `0600` security boundary; do not assert `0o600` for probe files on NTFS. Preserve the POSIX mode assertion on POSIX and inspect Windows ACLs separately if access control is under test.
- A cancelled suite leader can exit while descendants still run. The aggregate runner owns a separate process group per child and checks that group during bounded cleanup even after reaping the leader. Descendants that deliberately start a new session or process group are outside that group.
- `scripts/install.sh` derives most destinations from `$HOME` and has no general destination override. It invokes Codex-agent conversion first, so a read-only later skill, Copilot, Gemini, reference, or hook target can leave successfully refreshed Codex TOML while stopping the remaining copies. In that environment, report exactly which phase completed, validate source behavior, and leave the remaining refresh for a writable user shell; do not repurpose `HOME`.
- On macOS, `/var` can be a system symlink to `/private/var`; disposable homes created beneath it need path normalization before RTK destination link checks. Keep validation for links inside the normalized home so cleanup cannot traverse a user-created symlink.
- Normalize expected fixture roots with `pwd -P` before comparing them with `git rev-parse --show-toplevel`.
- Python 3.14 warns when a dynamic helper `__package__` disagrees with `ModuleSpec.parent`; use package-aware specs and remove every module under the unique test package prefix. Audit rotation fixtures belong in a disposable fixture repository, not the checked-out `.agents/` tree.
- `Popen` readers can emit `ResourceWarning` after partial reads unless all pipes are drained and closed; call `communicate()` and close any remaining streams during failure cleanup. Open-stdin hook tests must first prove bounded exit without EOF, then close stdin/stdout/stderr on every path. Warnings raised during finalization can accompany exit 0 even with `PYTHONWARNINGS=error::ResourceWarning`; capture fixture stderr and reject unexpected output rather than trusting exit alone.
- Immutable agent-brain paths reject every linked/reparse component. Normalize disposable system temp aliases physically before fixture construction; do not broadly relax source/destination link checks. Missing future owned knowledge directories are valid empty roots, while protected file mappings require exact read-only ownership.
- Setup apply/inverse must acquire the actual configured runtime `publication.lock`, including custom state paths. A similarly named sibling lock under `.agents/context/` only serializes setup/first initialization and does not exclude publication. Expected runtime identity remains outside state so deleting the directory cannot recreate authority or look never initialized.
- Managed inverse history must match the original reviewed-plan digest and derived journal path, with the exact forward/inverse set plus activation identity. A recomputed journal checksum alone cannot authorize additional policy/file changes.
- Root `.gitignore` changes alone cannot protect the first setup intent or retained data after rollback. Establish scoped local markers first, escape literal runtime path characters, preserve unrelated negation order, and keep markers after inverse effects. Git ignores cannot untrack existing private records, so those are explicit conflicts. Never hide portable knowledge/history by broadly ignoring `.agents/context/`.
- Installed native foreground and stage commands must retain their selected `--config`, including quoted custom paths. Dropping it can import a newer unactivated launcher default before native registration resolves the old pin; bind bootstrap selection before core import, then independently validate the issued configuration.
- If a problem is really `pwsh`-specific, keep it in `.agents/memory/known-issues/powershell.md`; do not dilute the shell doc with PowerShell details.
- A minimum pair count alone cannot establish a measured pilot: many copies of one variant omit longitudinal cycles, fresh checks and required native paths. Bind the entire independent frozen workload/matrix and typed observed prerequisites, not whatever checks the submitted output happens to claim. Later success cannot replace an earlier arm's preserved artifact snapshot or hash-bound independent review. Input-only token availability remains incomplete total provider task usage.
- Python object equality treats `True` as `1`, including inside nested metric records. Certification and critical review pins need typed/canonical comparison, not equality alone. A successful unsupported native envelope also does not prove that no effects occurred: validate calendar prerequisites before `brain.sqlite3` initialization and assert public unavailable context/no runtime state after rejection.
