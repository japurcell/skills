# T15b source artifact selection

`validateInstallSelection` is a stateless source validation boundary for a later installer. It accepts a canonical local bundle directory, an externally selected SHA256 of `release-manifest.json`, an exact pinned Node archive path, and optional Codex or Copilot artifact paths and requested native modes. It returns frozen descriptors with the release version/platform, archive URL/digest/size, and only the qualified provider version, model, reasoning and modes. It makes no destination ownership claim and writes nothing.

The existing schema 2 release consumer validates the external manifest digest, complete payload and directories, approved toolchain lock bytes, platform-specific Node asset table, and Windows helper pin. The Node archive remains outside that bundle. This selection hashes the actual archive through a bounded 64 KiB read buffer, refuses non-regular files, unsafe or linked path components, and requires the digest selected by the verified release manifest. Node archives are capped at 128 MiB. For Windows, the helper source path is derived only from the verified bundle's `native/windows-notify.exe` entry. Binding that helper to a dedicated installed root or shortcut belongs to the later install task.

Native provider selection is limited to `darwin-arm64`. Codex 0.163.0 requires executable SHA256 `8813367285524ac798dd96d1b071aea30d58708c7226fd236cd275cf1cfdee31`, with a 300 MiB source-file cap and requested modes drawn from `read-only` and `workspace-write`. Copilot 1.0.101 requires the full package closure against canonical manifest SHA256 `d7ff80ea8643df65f47546df95f77b07a7130d8bab8bc9ae8886eb23a913e696`, and only `read-only`. Both descriptors pin `gpt-6-luna` and `low`. The Copilot check calls the existing adapter artifact validator, which checks every package file's mode, size and streamed hash plus the complete inventory. Caller-supplied provider digests, platform claims, extra provider names, and unsupported or duplicate modes are refused. Gemini, OpenCode and Pi native selection remain explicitly blocked.

The official Node v24.22.1 [release checksums](https://nodejs.org/download/release/v24.22.1/SHASUMS256.txt) are the release table's independent archive authority. Provider artifact and mode evidence is bounded in [Codex qualification](codex.md) and [Copilot qualification](copilot.md). This validation does not execute either provider, inspect authentication, make a model call, download during ordinary tests, extract Node, install packages, persist credentials or environment, or modify a repository or desktop.

## Verification on 2026-10-22

Using the exact pinned Node 24.22.1, strict source and qualification typechecks and a fresh build receipt passed. The focused public selection test passes five cases with zero failures/skips: altered Node bytes, a self-consistent but unqualified Node digest, linked paths, altered bundle payload, caller support claims, invalid/sparse modes, wrong provider executable bytes and Linux attempting Darwin native support. The public release selector passes 18/18 cases. The affected Codex and Copilot fake-process adapter suites also pass, with no native provider subprocess or model call.

A separate disposable positive proof used a freshly packaged real schema 2 bundle, the exact official Darwin arm64 Node archive, the existing qualified Codex executable and the existing full 262-file Copilot package. The archive was absent from local caches, so only the exact release-table URL was fetched to `/private/tmp/factory-node-v24.22.1-darwin-arm64-selection.tar.xz` under a 128 MiB download cap and 120-second deadline. Its observed SHA256 was `654ba79de6155647e22321932b45f2a1ccb705976cc337c9b8e278beb085a628` and its size was 27,518,756 bytes. The public selector accepted all three sources, returned frozen descriptors, and reported Codex source size 249,952,688 bytes. A disposable copy of the Copilot package with one changed `index.js` byte was refused with `Copilot package closure mismatch`. The proof driver remains at `/private/tmp/factory-install-selection-positive-proof.mjs`; it creates and removes its own bundle and package copy. Mutable global provider paths are not mandatory fixtures in the maintained suite.

The descriptors certify source bytes at validation time. A later installer must stage and revalidate the selected bytes before publication, because another process can change a path after this function returns. This task does not claim native Windows execution or cross-host provider support.
