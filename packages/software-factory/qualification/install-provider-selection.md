# Public provider selection qualification

The public `install.py verify|prepare|install --providers ABS_JSON_FILE` route accepts only the optional `InstallSelection.providers` shape: `codex` with `executable` and unique nonempty modes from `read-only`, `workspace-write`; `copilot` with `packageRoot`, `manifestFile`, and only `read-only`. The JSON file is a canonical unlinked regular file of 1-4096 bytes. Its source paths are canonical, unlinked, and bounded. Duplicate keys, extra fields, deep or oversized JSON, unsupported modes, and malformed input refuse before selected JavaScript. Python copies the exact descriptor into the private stage, then the existing qualified Node validator hashes the selected artifacts. It revalidates the descriptor identity and bytes before candidate binding. The authenticated request carries original external paths; the candidate and installed receipt carry qualified digests and selected modes. Provider sources inside the factory or private stage refuse. Provider bytes are never copied into the installation.

`test/install-provider-selection.test.mjs` uses the actual public Python routes with archive-free disposable inputs. `qualification/install-provider-selection-native.qualification.mjs` is explicit, outside default discovery, and requires the exact Darwin arm64 Node 24.22.1 archive, Python 3.13.14, local copied offline cache, and previously qualified Codex 0.163.0 and Copilot 1.0.101 artifacts. It packages the current release, installs into a disposable dirty Git repository, loads both installed adapters through the pinned Node without starting either provider, checks selected modes and disabled notification preferences, and checks installed refusal after durable descriptor or external artifact tampering. It checks source and index preservation. Missing prerequisites fail the native test; there are no skips or substitutions.

This proof does not execute a provider, inspect credentials, establish native provider qualification, qualify Windows installation, or complete upgrade, repair, uninstall, and cleanup. Public installed acceptance remains bounded to the selected local sources and command-only workflow proof.
