## Native shim behavior and the direct candidate

On the pinned Darwin arm64 installation the selected target is `<fixture .git>/factory/toolchain/node_modules/@typescript/typescript-darwin-arm64/lib/tsc`, package version 7.0.2. The wrapper calls `process.execve(exe, [exe, '-p', config])`; env defaults to process.env, which is the compiler launch's empty environment. If replacement succeeds it never returns, the Node image disappears without JS exit/cleanup handlers, and the owned child PID remains the compiler process. Existing artifacts do not prove whether replacement succeeded on a particular historic invocation.

If execve throws, the catch silently enters `execFileSync(exe, ['-p', config], {stdio:'inherit'})`. That synchronous call returns on success. A nonzero native integer status becomes the wrapper's process.exitCode. A signal or spawn error without a truthy status is rethrown. The resulting wrapper error text/status can differ from a direct native launch. Its native subprocess inherits the wrapper's empty environment and group; this fallback adds a process and synchronous wait. Do not force this fallback or disable execve to manufacture an optimization baseline.

Candidate scope for a future private task: select this same validated compiler executable for pinned Darwin arm64 TypeScript 7.0.2 and call the existing `runner.execute(startup/build/id, {argv:[nativeCompiler,'-p',config], env:{}}, true)`. Keep the project/config/output/import steps and all existing checks. Keep the Node and TypeScript manifest checks even though Node stops being this one command's executable. Retain main typescript package/bin validation and authored dependency matching. Do not resolve through PATH, a global install, the package checkout's root compiler, a network acquisition, an unexported dynamically imported helper, or an arbitrary higher-level native package. Establish the selected package identity/version and exact local path from the same toolchain before launch; unavailable/mismatched/uncertain selection must fail closed without download or fallback to a different compiler.
