# Prototype native alert windows and gentle sounds

## Purpose / Big Picture

Move the accepted browser interaction into a disposable real desktop-window experiment on Windows, Ubuntu desktop, WSL2, and macOS. Verify native window presentation and direct WAV playback without installing real hooks or login items. The prototype must identify unsupported desktop/audio conditions instead of reporting silent success.

The current continuation completed the authorized Arch/WSLg checks in fresh isolated session-files experiments and fixed the reproduced Preview-label clipping in the disposable prototype using the user-approved Qt widget-layout seam and red/green TDD. No production or hook code, system packages, active audio devices, commits, or pushes were changed. WSLg acceptance is complete to the safe environment limits: physical output disconnection/recovery remains unverified, the user retired another virtual desktop/display for WSLg, and the optional QSoundEffect comparison was not requested. Native Ubuntu, Windows-host interoperability, and remaining macOS checks keep cross-platform acceptance open.
