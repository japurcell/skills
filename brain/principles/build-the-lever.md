# Build the Lever

Before automating a repeated operation, do one representative unit by hand. Build the smallest tool that reproduces that result and check it against the manual example before using it on the remaining units. For a couple of obvious edits, do them directly. When delegating a run, give the worker the recipe, allowed scope, and expected result.
