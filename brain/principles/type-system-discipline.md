# Type System Discipline

Give values with the same primitive representation distinct types when mixing them up would be a defect. Validate each value at construction. Make handling of variants exhaustive and derive shared shapes from their authoritative schema. For incoming data, apply [Boundary Discipline](boundary-discipline.md).
