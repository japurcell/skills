## Source facts and decision

Python `authenticate_bundle()` copies *every* fixed schema-2 manifest file into `PrivateStage` and checks original inventory/identity (`install.py:241-305`). It copies the SHA-pinned archive, applies the exact archive omission policy into `stage.root/node`, rehashes the copied bundle, then runs `validateInstallSelection()` from the **copied** bundle with the extracted direct Node (`install.py:627-653`). `PreparedSelection` holds original and snapshot paths, the manifest SHA, a bounded summary receipt and `revalidate_sources()` (`install.py:602-625`). The summary has count/bytes/omitted-link facts, but no hash of the extracted Node tree; a Node preparer given only `extracted_node_root` would have to trust arbitrary later path contents. `installation-bindings.ts:86-136` authenticates the copied release and archive, not extracted member bytes. Parent's sizing measurement is 6,690 candidate entries/231,178,610 bytes and 89 stage files/123,449,583 bytes (`/tmp/factory-candidate-directory-inclusive-proof.json`); this is sizing, not installation proof.

Extend Python's authenticated preparation scope with **one canonical digest of the entire extracted Node tree**, rather than serializing thousands of rows or inventing a signer. Python computes it after extraction from the private tree that `PrivateStage` owns; Node recomputes it before `beginRepositoryBootstrap()` and while copying into the candidate. The snapshot bundle and snapshot archive are separately revalidated through existing schema-2 `validateInstallSelection()`. This makes the Node tree a byte-and-mode-bound result of Python's pinned-archive extraction, rather than an asserted boolean. The private request is a same-process handoff fact, not a publisher signature or a general authority to install.

## Exact private request

Python adds a bounded `prepare` route using `prepare_install_selection(...)` and writes one owner-only, exclusive-create, fsynced `preparer-request.json` **inside its existing `PrivateStage`**, before spawning the verified direct Node. Pass only `--request <absolute private path>` to `snapshot_bundle_root/dist/install-entry.js`; no claim token or auth material enters argv or public output. Maximum request bytes: 64 KiB before UTF-8 JSON parse; reject duplicate/unknown fields, unsafe path lengths, noncanonical or linked parents, invalid integers and any path outside the recorded stage where a snapshot path is required. Exact schema:

```ts
interface PrivatePrepareRequestV1 {
  schema: 1;
  requestId: string; // fresh UUID, response correlation only
  repository: string; // caller-selected canonical Git repository path
  npm: { offline: boolean }; // fixed private cache/config paths derive from stageRoot
  stageRoot: string; // Python PrivateStage root, exact directory identity checked on both sides
  stageIdentity: string; // decimal st_dev:st_ino of that root, no secret
  source: {
    bundleRoot: string; manifestSha256: string; nodeArchivePath: string;
    providers?: InstallSelection['providers']; // external qualified paths/modes only
  };
  snapshot: {
    bundleRoot: string; nodeArchivePath: string; extractedNodeRoot: string;
    nodeTree: {
      schema: 1; digest: string; entries: number; regularBytes: number;
      omittedLinks: readonly string[];
    };
  };
}
```

`source.bundleRoot/nodeArchivePath` are the original user-selected canonical paths. `snapshot.bundleRoot` is `PreparedSelection.snapshot_bundle_root`, `snapshot.nodeArchivePath` is its `snapshot_node_archive`, and `snapshot.extractedNodeRoot` is its `extracted_node_root`; require those exact children under `stageRoot`, not caller-supplied arbitrary paths. `stageIdentity` is Python's observed directory device/inode, checked against Node's `lstat` before and after source validation; the Python owner also calls `PrivateStage.check('')` before launch and after child exit. If a platform cannot establish the comparison or private ownership, fail closed pending native qualification. The `providers` object is optional, bounded to the existing Codex/Copilot selection shape and never copied or executed. Python only forwards its paths/modes; bundled JS performs the existing complete qualification check before bootstrap. Python must not silently drop a selected provider mode.

Define the `nodeTree.digest` algorithm once in an adjacent contract/test fixture shared by Python and Node. Start SHA256 with `factory-node-tree-v1\0`. Walk the actual extracted root without following links, sort all relative UTF-8 paths bytewise, and for each directory append `D\0<path>\0<octal-mode>\0`; for each regular file stream a SHA256 over its bytes and append `F\0<path>\0<decimal-size>\0<octal-mode>\0<32 raw digest bytes>`. Paths use `/`, exclude the root itself, and include every directory, including empty and implicit archive ancestors. Mode is observed `st_mode & 0o777`, with the existing extraction policy (`0700` direct Node, `0600` other files, `0700` directories); Windows must pass its own same-runtime mode/ACL qualification rather than silently normalize a mismatch. Reject links/reparse/special files, case collisions, unsafe components, changed open-file identity/size/mtime during streaming, extra entries and count/byte overflow. `entries` includes both files and directories. Reuse the **candidate** 8,192-entry, 512-MiB total, 128-MiB/file, 512-byte/path and depth-32 limits at the handoff tree scan, while the archive parser keeps its already accepted 8,192-member/256-MiB rules. For the selected tree the measured full candidate remains below those limits; measure the final Node tree again with new compiled modules at acceptance.

Node `install-entry` opens the private request without following links, checks owner-only type/size and stable file identity, parses the exact schema, and validates the stage root and child paths. It calls `validateInstallSelection({bundleRoot: snapshot.bundleRoot, manifestSha256: source.manifestSha256, nodeArchivePath: snapshot.nodeArchivePath, providers: source.providers})` **before any factory/store mutation**. It recomputes the full `nodeTree` digest/count/bytes against `snapshot.extractedNodeRoot`, compares omission table to the selected platform, then validates the original `source` selection through the same existing validator and requires matching version/platform/archive/manifest/provider facts. The original source may be rehashed again immediately before candidate binding; Python `PreparedSelection.revalidate_sources()` runs immediately before launch and after child exit. Source changes detected at either check refuse success and leave any acquired claim incomplete for inspection. Candidate authenticity is anchored in the authenticated private snapshot even if an original path changes in the narrow interval between checks; no mutable-original-path claim becomes an installed-ready fact.

When copying Node into `factory/install-candidate-<operationId>/install/node/`, open each source file without following links, compare before/after descriptor and path identity, create destination exclusively, copy in bounded chunks while hashing, preserve the validated mode, and compare each destination hash/size/mode. Recompute the source tree digest after copy and compare to Python's `nodeTree.digest`; compute the destination subtree digest and require equality before candidate receipt/binding. A mismatch leaves the incomplete operation and unbound partial candidate. The complete release snapshot is copied with each schema-2 manifest hash, exact directory inventory and a final `validateReleaseBundle(candidate/install/runtime, selectedManifestSha)`; never execute/import a module from the original bundle, old installation, or candidate before source validation. The later operation-owned candidate receipt binds the resulting per-file inventory and tree digest; the Python request itself is temporary and is not an installed receipt.
