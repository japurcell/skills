## Candidate construction and binding

Use the manifest SHA as `targetReleaseSha256`; use sorted names `bundle`, `node`, and each selected qualified provider/helper in `artifactDigests`; SHA256 a canonical versioned serialization of release version, platform, exact manifest/archive digests, selected provider canonical paths, digests and modes, Windows helper selection, and target schema 7 as `selectionDigest`. Persist a private descriptor with those immutable external provider paths/modes. `beginRepositoryBootstrap` may retain its shape-only selection interface for controller tests, but a shape-only install claim cannot advance to install handoff or ready.

After Python authentication and `validateInstallSelection()`, call `beginRepositoryBootstrap(repository, derivedSelection, currentOwner())`. Under the returned Git-common `factory/`, create `install-candidate-<operationId>/` **absent-only and nonrecursive**. Require new private directory identity (device/inode plus canonical path), private permissions/ACL qualification, no links, and no preexisting target. Its exact children at bind are `install/`, `toolchain/`, and `candidate-receipt.json`; `install/runtime/` is the complete manifest-bound release bundle, `install/node/` is the extracted regular Node distribution with only the three exact POSIX convenience links omitted, and `toolchain/` contains the manifest-bound declaration/lock, installed closure, and `manifest.json`. Copy files with exclusive create, stream source and destination hashes, verify size/mode/identity after writes, flush files and owned directories, and revalidate the frozen source descriptor after copy. A source change, dirty Git index/worktree mutation, foreign candidate entry, linked destination, or ambiguous partial directory fails closed. A crash before binding retains the incomplete claim and partial tree for inspection; it is never adopted by a retry. Reclaim may rotate an unbound claim only if its deterministic candidate path is absent. A bound candidate survives token rotation only after full validation.

Run the candidate's direct Node and npm script from `install/node/`: POSIX `bin/node lib/node_modules/npm/bin/npm-cli.js`, Windows `node.exe node_modules/npm/bin/npm-cli.js`. Reject declaration/lock changes, extra packages or files, links/shims, unexpected package versions/integrities, and incomplete platform optional closure.
