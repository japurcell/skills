The official [release tag API](https://api.github.com/repos/microsoft/typescript-go/git/ref/tags/typescript/v7.0.2) resolves directly to commit `2bd066d87f5bafd315be9f40889d0a60b9e58e0b`, matching installed and archive package `gitHead`. Downloaded the lock-pinned npm URL into `/tmp/factory-typescript-win32-x64-7.0.2.tgz`. Its SHA512 matches package-lock.json exactly, and its SHA256 matches that official release digest. Archive member `package/lib/tsc.exe` is 24,520,544 bytes with SHA256 `f9ecfbdc93753d2c972d66a8d0d75f5bd737fd4a5f88b422d9091ea282bcb2c7`. No executable was launched or installed.

Resolved the official Contents API before downloading the immutable source into `/tmp/factory-typescript-7.0.2-source/microsoft-typescript-go-2bd066d/`. [cmd/tsgo/main.go](https://github.com/microsoft/typescript-go/blob/2bd066d87f5bafd315be9f40889d0a60b9e58e0b/cmd/tsgo/main.go) sends first argument --lsp to runLSP and --api to runAPI. Other arguments call execute.CommandLine. [internal/execute/tsc.go](https://github.com/microsoft/typescript-go/blob/2bd066d87f5bafd315be9f40889d0a60b9e58e0b/internal/execute/tsc.go) selects build only for first-argument build flags, parses an explicit project, then performs ordinary compilation unless config enables watch/incremental. [cmd/tsgo/sys.go](https://github.com/microsoft/typescript-go/blob/2bd066d87f5bafd315be9f40889d0a60b9e58e0b/cmd/tsgo/sys.go) uses the bundled library plus OS filesystem.

An initial source search for process launch APIs in cmd/internal found one production exec.Command call in LSP's npm path; other matches were tests/test utilities. Fixed -p invocation excludes the LSP first-argument route. This search and entry-point tracing are partial evidence, not a complete import/dependency call-graph proof. Continue reviewing Windows filesystem/runtime dependencies and factory-generated config before promotion. Do not infer that arbitrary compiler flags or user configs qualify.

Native tests must exercise hostile environment/configuration without silently changing accepted checkout behavior.
