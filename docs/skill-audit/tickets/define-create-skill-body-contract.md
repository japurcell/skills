# Define Create Skill Body Contract

**Type:** grilling
**Status:** open
**Blocked By:** review-skill-authoring-and-repository-guidance.md
**Research Dir:** not applicable

## Question

Does Create Skill intentionally require the seven body headings checked by its evals and grader, or should its output structure follow a more flexible contract?

[SAG-003](../findings.md#sag-003-undefined-anatomy-expectation) owns the evidence. The entry promises an anatomy pattern without defining those headings; its imported helper defines bundle/directory anatomy. Evals and the grader require Overview, When to Use, Workflow, Specific Techniques, Common Rationalizations, Red Flags, and Verification. Existing evals support intent but cannot establish a protected output contract by themselves.

Decide the intended output structure and its applicability. If those headings are intended, authorize their explicit definition or maintained reference as an authoring improvement. If a flexible structure is intended, identify the separate output/eval change and acceptance evidence. Preserve names, purpose, dependencies, approval boundaries, and useful exceptions. Do not impose this template on unrelated skills.
