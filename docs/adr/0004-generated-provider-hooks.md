# Generate checked-in provider-local hooks from canonical sources

Shared hook behavior will be maintained as canonical source under `hooks/` and rendered by `scripts/generate-hooks.py` into checked-in, provider-local Python files under `.copilot/`, `.gemini/`, and `.github/`. Generated files remain self-contained at runtime and never import across provider directories; this preserves runtime isolation while replacing duplicated human-maintained logic with one source of truth. Generated outputs must carry a do-not-edit marker, pass a repository freshness check, and preserve current provider behavior before any drift is corrected in a separate change. This model was chosen over cross-provider runtime imports, which weaken deployment isolation, and parity tests alone, which detect drift without removing duplicate maintenance.
