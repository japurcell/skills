## Codebase Patterns

- In native Windows PowerShell under tool guard, avoid `@()` or `$()` subexpression syntax; use simple commands or pipeline execution.
- Native `rtk grep` requires `grep` binary on PATH; on Windows PowerShell, use `Select-String`, `cmd /c dir /b`, or Python scripts.
- `read_file` tool only operates inside workspace roots; use shell commands (`cmd /c dir /b`, `Get-FileHash`, `Get-ChildItem`) to inspect paths outside workspace (e.g. `~/.copilot/session-state/`).
- Markdown files under `.agents/` must satisfy OKF profile linting via `python scripts/lint-okf.py`.
- Tool Guardian enforces a 32,768-character input bound and 128-segment bound on edits; keep patch edits small and focused.
