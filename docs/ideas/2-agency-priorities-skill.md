# Agency Priorities Skill

Create a skill that gives agents knowledge of USDA and Forest Service priorities from canonical sources.

- [USDA Strategic Plan](https://www.usda.gov/about-usda/general-information/our-performance)
  - Open the PDF for the current strategic plan.
- [Forest Service Priorities](https://www.fs.usda.gov/about-agency/priorities)

Name the skill `agency-priorities` and create it in `skills/forest-service/`.
