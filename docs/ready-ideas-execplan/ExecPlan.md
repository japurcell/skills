# Make agent guidance and local hooks reliable across providers

This ExecPlan is a living document. Keep `Progress`, `Surprises & Discoveries`, `Decision Log`, and `Outcomes & Retrospective` current as work proceeds. Follow `.agents/skills/exec-plans/SKILL.md`.

## Purpose / Big Picture

Agent sessions currently expose a misleading RTK notice, can miss broken Markdown, and have inconsistent security feedback. A Windows session-end secret scan can stall, while guidance can cause wasted reading or misplaced scripts. After this plan is implemented, local Copilot CLI, Gemini CLI, and Codex agents will have the agreed guidance and hooks. A user can see concise Markdown diagnostics and security decisions, run explicit RTK commands without the false notice, and finish a stalled secret scan without waiting on a pipe reader. The plan also protects Git metadata and local edits as far as provider hooks and verified platform controls permit.

This plan covers all eight former Ready ideas. It creates one independently verifiable milestone for each, one shared hook setup milestone, and two later live-verification milestones for providers absent from the current host. It does not claim that a hook can monitor every child process or that a live Windows run is required to finish. The [Disposable Probe Files] guidance is intentionally narrower: only three instruction files change for that milestone, with no installer, agent-run, or Windows checks.
