- Keep effort artifacts under `docs/just-in-time-context/`; domain-modeling is waived. Closed tickets own the accepted contracts.
- agent-brain names the skill and CLI. Foreground agents perform semantic recall/learn/dream. The core performs deterministic retrieval, state/checks and publication, with thin native adapters. No independent model runner, daemon or maintenance subagent is required.
- Indexed Markdown remains authoritative. Preserve OKF frontmatter, stable IDs, applicability/exceptions/references and explicit loading order. Map protected artifacts in place. Knowledge/config/candidates/semantic history are versioned; persistent runtime is ignored and worktree-local.
- Evidence is proportional. Low-risk tips need observed failure/workaround/scope. Stronger rules, correction and pruning need appropriate stronger checks. Age/inactivity only prioritize review; pruning requires error, obsolescence or complete redundancy. External evidence gains no instruction authority.

- Default stage budget is three total attempts and at most one semantic repair. Duplicate events do not reset it. Pauses/cancellation revoke authority without restarting canceled objectives. Pending obligations recover at the next eligible supported event; idle/shutdown carry no unconditional execution promise.
- Children receive verified assigned context; parent owns aggregate learning/routine dream. Unsupported child, resume/compaction, timeout/advisory and entry paths stay explicit.
- First-version targets: Codex desktop and Codex/Copilot/Gemini CLIs. Both VS Code harnesses are deferred. Certify each exact deployed build/platform/filesystem/mode/permissions/configuration independently. Native Windows live testing here is limited to Copilot and Gemini, never Codex.

Seven initial cohorts mean at least 840 baseline/candidate task executions before additional cycle tasks/probes. Freeze counts, order, expected checks, models, capture/tokenizer and windows before paid runs.
